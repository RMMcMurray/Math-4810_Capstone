1 Overview

This notebook searches for the best linear model — one that trades off predictive power (test R²), interpretability, and the reasonableness of classical linear-model assumptions. A parallel nonlinear (black-box) model will be built in a later notebook; here we focus on models whose coefficients can be read directly.

The core workflow is:

  1. Re-run the shared data-prep pipeline.
  2. Drop outliers using influence diagnostics (Cook’s D, studentized residuals, feature tails) while staying under the 10% ceiling.
  3. Split train/test (80/20, random_state=2026).
  4. Fit many linear model variants — base OLS, OLS with polynomial and interaction terms, shrinkage (Ridge / Lasso / ElasticNet), robust fits (Huber / WLS / Quantile), dimension-reduction fits (PCR / PLS), and segment-stratified OLS.
  5. Score each by train R², test R², 5-fold CV R², AIC, and assumption diagnostics; rank by test R² with a sanity check on the train–test gap.
  6. Re-fit the winner, pull its coefficient table, and inspect residuals.

6 Feature-Engineering Helpers

To keep the later chunks short, we define a helper that builds the polynomial + segment-interaction feature set on top of the base matrix. Four continuous variables get a squared term; each segment_* dummy gets multiplied by the six key numeric predictors.

Code 
POLY_COLS   = ['ln_GLA', 'Quality_Weighted', 'EffYearBuilt_Weighted', 'AsinH_Acreage']
KEY_NUMERIC = ['ln_GLA', 'Quality_Weighted', 'EffYearBuilt_Weighted',
               'AsinH_Acreage', 'AsinH_Land_Value', 'AsinH_Total_Value']
seg_cols    = [c for c in X_train.columns if c.startswith('segment_')]

def build_poly_seg(X_in, ref_cols=None):
    X2 = X_in.copy()
    for c in POLY_COLS:
        if c in X2.columns:
            X2[f'{c}_sq'] = X2[c] ** 2
    for sc in seg_cols:
        for kn in KEY_NUMERIC:
            if kn in X2.columns:
                X2[f'{sc}_x_{kn}'] = X2[sc] * X2[kn]
    if ref_cols is not None:
        X2 = X2.reindex(columns=ref_cols, fill_value=0)
    return X2

X_train_v2 = X_train.copy()
X_test_v2  = X_test.copy()
for c in POLY_COLS:
    if c in X_train_v2.columns:
        X_train_v2[f'{c}_sq'] = X_train_v2[c] ** 2
        X_test_v2[f'{c}_sq']  = X_test_v2[c]  ** 2

X_train_v3 = X_train.copy()
X_test_v3  = X_test.copy()

9 Lasso-Select → OLS Refit

Lasso already shrinks the model toward a parsimonious subset; refitting plain OLS on those selected features gives us:

  • unbiased (non-shrunk) coefficient estimates for inference, and
  • the textbook diagnostic machinery (AIC, BIC, Breusch-Pagan, etc.).

This is a classic two-stage selection pipeline — Lasso for feature identification, OLS for interpretation.

Code 
def lasso_then_ols(Xtr_s_arr, Xte_s_arr, Xtr_df, Xte_df, lasso_model, label):
    sel_idx   = np.where(lasso_model.coef_ != 0)[0]
    sel_names = Xtr_df.columns[sel_idx].tolist()

    # Refit OLS on UNSCALED selected features for interpretable coefficients
    Xtr_sel = Xtr_df[sel_names]
    Xte_sel = Xte_df[sel_names]

def run_wls(X_in_tr, X_in_te, label):
    Xc_tr = sm.add_constant(X_in_tr, has_constant='add')
    Xc_te = sm.add_constant(X_in_te, has_constant='add').reindex(
                columns=Xc_tr.columns, fill_value=0)

    # Stage 1 — OLS to estimate variance structure
    ols_s1 = sm.OLS(y_train, Xc_tr).fit()
    fv     = ols_s1.predict(Xc_tr).values
    res_s1 = y_train.values - fv

    # log(|resid|²) ≈ function of fitted values → exp gives σ²
    var_model = sm.OLS(np.log(res_s1 ** 2 + 1e-8),
                        sm.add_constant(fv)).fit()
    w = 1.0 / np.exp(var_model.predict(sm.add_constant(fv)))

    wls = sm.WLS(y_train, Xc_tr, weights=w).fit()
    yhat_tr, yhat_te = wls.predict(Xc_tr), wls.predict(Xc_te)
    r2_tr, r2_te = r2_score(y_train, yhat_tr), r2_score(y_test, yhat_te)

    print("=" * 55)
    print(f"  {label}")
    print("=" * 55)
    print(f"  Train R² / Test R² : {r2_tr:.4f}  /  {r2_te:.4f}")
    print(f"  Train–Test gap     : {r2_tr - r2_te:+.4f}")

    record(model=label, r2_train=r2_tr, r2_test=r2_te, n_feat=X_in_tr.shape[1])
    return wls

14.3 Assumption Check — What Passes and What Doesn’t

  • Linearity — the residuals-vs-fitted cloud is centered on zero across the full fitted range, with no clear curvature. ✅
  • Independence — Durbin-Watson ≈ 2.01. ✅
  • Normality of residuals — skew ≈ −0.07 (essentially symmetric); kurtosis ≈ 2.79 (slightly leptokurtic, tails a bit fatter than Gaussian). The Q-Q plot is straight through most of the range with mild tail deviation. ✅ reasonable — not pristine.
  • Homoscedasticity — Breusch-Pagan p ≈ 0. ❌ Variance does grow with fitted value. Classical standard errors should be taken with a grain of salt. For inference-heavy questions, robust (HC3) standard errors or a WLS refit on these 34 features would be the textbook fix; for the prediction task the heteroscedasticity does not distort point predictions, it only distorts the SEs.

Practical takeaway: point estimates and test R² are trustworthy. If you plan to report confidence intervals for coefficients, use winner.get_robustcov_results('HC3').

14.4 What the Model Is Saying

The largest-magnitude coefficients (by |t|) trace to four intuitive sources:

  1. Assessor-aligned capital stock — AsinH_Total_Value (+0.28) and ln_GLA (+0.23) dominate, exactly as you’d expect: more square footage, higher assessed total, higher sale price.
  2. Property-type dummies — SpecificPropTypeDescription_DEFAULT (−1.32) and _CONDOMINIUM / TOWNHOUSE (−0.08) carve out known discounts relative to the base category.
  3. Quality curvature — the selected Quality_Weighted_sq (+0.012) captures the convex relationship: moving from quality 3 to 4 is worth less than from 4 to 5.
  4. Segment / style fixed effects — segment_Residential (−0.025), NbhdCode2_M (+0.125), Main_StyleDesc_One Story, etc., pick up the residual unexplained location/style premium.

Of the engineered features:

  • Both squared terms from the polynomial set (Quality_Weighted_sq, EffYearBuilt_Weighted_sq) were retained.
  • Only one of the segment × numeric interactions survived: segment_Multi-Family × AsinH_Acreage. All others were shrunk to zero by Lasso. This is strong evidence that the pricing response to continuous predictors is roughly constant across segments for this market — the multi-family relationship with acreage is the one real exception.

14.5 Back-Transforming to Dollars

On the log-scale the test MAE is 0.0805. In dollar terms that’s roughly

\[ \text{median test } \$ \text{ error} \approx \overline{P_{\text{test}}} \cdot \left(e^{0.0805} - 1\right) \approx \$34{,}700 \]

on properties whose test-set mean sale price is ≈ $410K. That’s ≈ 8.4% of the mean sale price — a workable error band for appraisal-style use, though wider at the tails given the heteroscedasticity.

# Overview

This notebook searches for the best *linear* model — one that trades off
predictive power (test R²), interpretability, and the reasonableness of
classical linear-model assumptions.  A parallel nonlinear (black-box)
model will be built in a later notebook; here we focus on models whose
coefficients can be read directly.

1.  Re-run the shared data-prep pipeline.
2.  Drop outliers using influence

    staying under the 10% ceiling.
3.  Split train/test (80/20, `random_state=2026`).

# Feature-Engineering Helpers

To keep the later chunks short, we define a helper that builds the
**polynomial + segment-interaction** feature set on top of the base
matrix.  Four continuous variables get a squared term; each `segment_*`
dummy gets multiplied by the six key numeric predictors.

```{python}
#| label: feature_builder

POLY_COLS   = ['ln_GLA', 'Quality_Weighted', 'EffYearBuilt_Weighted', 'AsinH_Acreage']
KEY_NUMERIC = ['ln_GLA', 'Quality_Weighted', 'EffYearBuilt_Weighted',
               'AsinH_Acreage', 'AsinH_Land_Value', 'AsinH_Total_Value']
seg_cols    = [c for c in X_train.columns if c.startswith('segment_')]

def build_poly_seg(X_in, ref_cols=None):
    X2 = X_in.copy()
    for c in POLY_COLS:
        if c in X2.columns:
            X2[f'{c}_sq'] = X2[c] ** 2
    for sc in seg_cols:
        for kn in KEY_NUMERIC:
            if kn in X2.columns:
                X2[f'{sc}_x_{kn}'] = X2[sc] * X2[kn]
    if ref_cols is not None:
        X2 = X2.reindex(columns=ref_cols, fill_value=0)
    return X2

X_train_v2 = X_train.copy()
X_test_v2  = X_test.copy()
for c in POLY_COLS:
    if c in X_train_v2.columns:
        X_train_v2[f'{c}_sq'] = X_train_v2[c] ** 2
        X_test_v2[f'{c}_sq']  = X_test_v2[c]  ** 2

X_train_v3 = X_train.copy()
X_test_v3  = X_test.copy()
for sc in seg_cols:
    for kn in KEY_NUMERIC:
        if kn in X_train_v3.columns:
            X_train_v3[f'{sc}_x_{kn}'] = X_train_v3[sc] * X_train_v3[kn]
            X_test_v3[f'{sc}_x_{kn}']  = X_test_v3[sc]  * X_test_v3[kn]

X_train_v4 = build_poly_seg(X_train)
X_test_v4  = build_poly_seg(X_test, ref_cols=X_train_v4.columns)

print(f"v1 (base)        : {X_train.shape[1]} features")
print(f"v2 (poly)        : {X_train_v2.shape[1]} features")
print(f"v3 (seg × num)   : {X_train_v3.shape[1]} features")
```

# Lasso-Select → OLS Refit

Lasso already shrinks the model toward a parsimonious subset; refitting
plain OLS on those selected features gives us:

-   unbiased (non-shrunk) coefficient estimates for inference, and
-   the textbook diagnostic machinery (AIC, BIC, Breusch-Pagan, etc.).

This is a classic two-stage selection pipeline — Lasso for feature
identification, OLS for interpretation.

```{python}
#| label: lasso_then_ols

def lasso_then_ols(Xtr_s_arr, Xte_s_arr, Xtr_df, Xte_df, lasso_model, label):
    sel_idx   = np.where(lasso_model.coef_ != 0)[0]
    sel_names = Xtr_df.columns[sel_idx].tolist()

    # Refit OLS on UNSCALED selected features for interpretable coefficients
    Xtr_sel = Xtr_df[sel_names]
    Xte_sel = Xte_df[sel_names]
    Xc_tr   = sm.add_constant(Xtr_sel, has_constant='add')
    Xc_te   = sm.add_constant(Xte_sel, has_constant='add').reindex(
                columns=Xc_tr.columns, fill_value=0)

    m = sm.OLS(y_train, Xc_tr).fit()
    yhat_tr, yhat_te = m.predict(Xc_tr), m.predict(Xc_te)
    resid = y_train.values - yhat_tr.values
    r2_tr, r2_te = r2_score(y_train, yhat_tr), r2_score(y_test, yhat_te)
    stats_d = assumption_stats(resid, Xc_tr)

    print("=" * 55)
    print(f"  {label}")
    print("=" * 55)
    print(f"  Selected features  : {len(sel_names)} / {Xtr_df.shape[1]}")
    print(f"  Train R² / Test R² : {r2_tr:.4f}  /  {r2_te:.4f}")
    print(f"  Train–Test gap     : {r2_tr - r2_te:+.4f}")
    print(f"  AIC                : {m.aic:.1f}")
    print(f"  Breusch-Pagan p    : {stats_d['bp_p']:.2e}")
    print(f"  Durbin-Watson      : {stats_d['dw']:.3f}")
    print(f"  Resid skew / kurt  : {stats_d['skew']:+.3f} / {stats_d['kurt']:.3f}")

    record(model=label, r2_train=r2_tr, r2_test=r2_te,
           aic=m.aic, bic=m.bic, n_feat=len(sel_names), **stats_d)
    return m, sel_names
```

## WLS (Variance-Structure Weights)

```{python}
#| label: wls

def run_wls(X_in_tr, X_in_te, label):
    Xc_tr = sm.add_constant(X_in_tr, has_constant='add')
    Xc_te = sm.add_constant(X_in_te, has_constant='add').reindex(
                columns=Xc_tr.columns, fill_value=0)

    # Stage 1 — OLS to estimate variance structure
    ols_s1 = sm.OLS(y_train, Xc_tr).fit()
    fv     = ols_s1.predict(Xc_tr).values
    res_s1 = y_train.values - fv

    # log(|resid|²) ≈ function of fitted values → exp gives σ²
    var_model = sm.OLS(np.log(res_s1 ** 2 + 1e-8),
                        sm.add_constant(fv)).fit()
    w = 1.0 / np.exp(var_model.predict(sm.add_constant(fv)))

    wls = sm.WLS(y_train, Xc_tr, weights=w).fit()
    yhat_tr, yhat_te = wls.predict(Xc_tr), wls.predict(Xc_te)
    r2_tr, r2_te = r2_score(y_train, yhat_tr), r2_score(y_test, yhat_te)

    print("=" * 55)
    print(f"  {label}")
    print("=" * 55)
    print(f"  Train R² / Test R² : {r2_tr:.4f}  /  {r2_te:.4f}")
    print(f"  Train–Test gap     : {r2_tr - r2_te:+.4f}")

    record(model=label, r2_train=r2_tr, r2_test=r2_te, n_feat=X_in_tr.shape[1])
    return wls
```

## Assumption Check — What Passes and What Doesn't

-   **Linearity** — the residuals-vs-fitted cloud is centered on zero
    across the full fitted range, with no clear curvature.  ✅
-   **Independence** — Durbin-Watson ≈ 2.01.  ✅
-   **Normality of residuals** — skew ≈ −0.07 (essentially symmetric);
    kurtosis ≈ 2.79 (slightly leptokurtic, tails a bit fatter than
    Gaussian).  The Q-Q plot is straight through most of the range with
    mild tail deviation.  ✅ *reasonable* — not pristine.
-   **Homoscedasticity** — Breusch-Pagan p ≈ 0.  ❌  Variance does grow
    with fitted value.  Classical standard errors should be taken with a
    grain of salt.  For inference-heavy questions, robust (HC3) standard
    errors or a WLS refit on these 34 features would be the textbook fix;
    for the prediction task the heteroscedasticity does not distort
    point predictions, it only distorts the SEs.

Practical takeaway: point estimates and test R² are trustworthy.  If you
plan to report confidence intervals for coefficients, use
`winner.get_robustcov_results('HC3')`.

## What the Model Is Saying

The largest-magnitude coefficients (by |t|) trace to four intuitive
sources:

1.  **Assessor-aligned capital stock** — `AsinH_Total_Value` (+0.28) and
    `ln_GLA` (+0.23) dominate, exactly as you'd expect: more square
    footage, higher assessed total, higher sale price.
2.  **Property-type dummies** — `SpecificPropTypeDescription_DEFAULT`
    (−1.32) and `_CONDOMINIUM / TOWNHOUSE` (−0.08) carve out known
    discounts relative to the base category.
3.  **Quality curvature** — the selected `Quality_Weighted_sq`
    (+0.012) captures the convex relationship: moving from quality 3 to

4.  **Segment / style fixed effects** — `segment_Residential` (−0.025),

-   Both squared terms from the polynomial set

-   Only **one** of the segment × numeric interactions survived:

    market — the multi-family relationship with acreage is the one real
    exception.
